Digit Dictation

Each round has 10 questions. Pattern 334 is spoken as 3 digits, then 3, then 4. The same digit repeated inside a group is spoken as double or triple. Type while they play. 0 is spoken as oh.

Each round has 10 questions. A flight number is two letters, then 3 digits. Choose 4, or 3 or 4, when you want a longer number. It is spoken as one phrase, like B A, two oh seven. 0 is oh, and a repeated digit is double or triple. Type while they play.

Each round has 10 UK postcodes. Choose a form, or Mixed. W1A 0AX also brings SW1A, EC1A, and WC1A. Each one is spoken as a phrase, with a short pause before the last three characters. 0 is oh, and a repeated character is double. Type while they play.
